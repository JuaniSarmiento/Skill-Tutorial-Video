# Fuentes del formato «clase»

Las usa la composición de Remotion (`assets/remotion/src/Clase.tsx`); `clase.py` las copia al
directorio público de cada render. Las tres son libres bajo la SIL Open Font License 1.1 (el texto
de cada licencia, con su copyright, está al lado):

| Archivo | Uso | Licencia |
|---|---|---|
| `Kalam-Bold.ttf` | letra de fibrón en la pizarra (nunca para código) | `OFL-Kalam.txt` |
| `JetBrainsMono-Regular.ttf`, `JetBrainsMono-ExtraBold.ttf` | código y terminal (ligaduras desactivadas) | `OFL-JetBrainsMono.txt` |
| `Fredoka.ttf` | subtítulos y títulos de las ventanas | `OFL-Fredoka.txt` |
